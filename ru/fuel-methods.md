# Методы расчета расхода и их калибровочные коэффициенты

Обычно сам автомобиль (и его ЭБУ) не сообщает сколько в каждый момент расходуется топлива. Хобдрайв использует показания групп датчиков для вычисления этого значения.

Конечно, вычисленное значение зависит от многих внешних условий, известных и не известных.

На разных автомобилях и ЭБУ используются различные методы подсчета расхода.

Это зависит от информации, которая поступает с ЭБУ. На некоторых авто может быть поддержка нескольких методов расчета.

Обзор внешнего вида диалогов настройки: https://vk.ru/video-45441804_456239020

## Алгоритмы расчета расхода топлива

Метод расчета расхода топлива выбирается на экране «Параметры Автомобиля»:

- Экраны -> Настройка

- Параметры автомобиля -> Метод расчета топлива

Экран предлагает настроить метод расчета и его параметры, и одновременно контролировать "Часовой расход".

В случае, если вы не уверены какой метод поддерживает ваш автомобиль, выбирайте последовательно начиная с первого и контролируйте показания «Часовой расход» (на этом же экране), но обязательно на холостом ходу!

Если "Часовой расход" показывает прочерк, то этот метод вам не подходит, если показания слишком завышенные или слишком заниженные - датчик покажет желтый/красный оттенок.


При настройке метода расхода топлива нет смысла смотреть на показатель "Расход топлива" в литрах на 100км. Этот показатель показывает правильные данные только когда автомобиль движется и набрана достаточная статистика.


В программе доступно несколько алгоритмов.

### MAF Датчик

Это вариант по умолчанию для большинства современных бензиновых автомобилей. Расчёт топлива в этом варианте ведётся по MAF (Mass Air Flow, ДМРВ, Датчик массового расхода воздуха). Это достаточно точный метод при условии что автомобиль исправен и подает стехиометрическую смесь.
Калибровочные коэффициенты для метода MAF:
– Коэффициент Топливо-воздушной смеси (AFR): Основная константа, означающая отношение массы воздуха к массе топлива, попавшего в камеры сгорания.
Значение по умолчанию: «14.7»


Примеры для различных видов топлива (Воздух :Топливо) (AFR)
Неэтилированный бензин 14,7:1
Пропан (сжиженный газ) 15,5:1
Метан (сжатый газ) 17,2:1
Дизельное топливо 14,6:1
Метанол (метиловый спирт) 6,4:1
Этанол (этиловый спирт) 9,0:1


### MAP Датчик
Подсчёт расхода по MAP датчику (Manifold Absolute Pressure, Давление на впускном коллекторе). Альтернатива методу MAF.

На автомобилях без MAF используется MAP, температура впуска, объемная эффективность и обороты для определения расчетного значения потока воздуха.
Калибровочные коэффициенты для метода MAP:
– Коэффициент Топливо-воздушной смеси (AFR) — Аналогичен предыдущему описанию.
– Объем двигателя: Объем двигателя в литрах. Значение по умолчанию: «1.8» литра.
– Объемная эффективность (Volumetric Efficiency VE): Корректировочная константа для оценки эффективности использования попавшего в камеры сгорания двигателя. Значение по умолчанию: «95».


### Датчик Форсунки

Подсчёт расхода по доступному на некоторых автомобилях датчику Импульса Форсунки ("InjectorPulseWidth"). На протоколе OBD2 этот датчик недоступен.
Калибровочные коэффициенты для метода «Injector Sensor»
– Число цилиндров: Число цилиндров в двигателе. Значение по умолчанию: «4» цилиндра.
– Производительность форсунки: Количество топлива в мл/мин, впрыскиваемого одной форсункой. Исторически в хобдрайве указывается половина реальной производительности форсунки. Значение по умолчанию: «134.23» мл/мин (для реальной производительности 268 мл/мин).


### Датчик нагрузки на двигатель (дизель)

Подсчёт расхода топлива по датчику нагрузки на двигатель. Дает грубое приближение данных о расходе, используется только для дизельных автомобилей. Требует калибровки.
Калибровочные коэффициенты для метода «EngineLoad Sensor»
– Коэффициент расхода по нагрузке: Глобальный корректирующий коэффициент. Значение по умолчанию: «1»
– Кривая коэффициента по нагрузке: Используется для детальной подстройки расчёта расхода. Значение состоит из группы чисел, разделённых запятой. Каждое число означает коэффициент расхода при определённом RPM (от 0rpm до 10000rpm). Шаг rpm определяется количеством чисел в строке ( для десяти чисел, шаг RPM будет 1000).
Значение по умолчанию:
«0.025, 0.025, 0.10, 0.20, 0.3, 0.4, 0.3, 0.3, 0.3, 0.3»
Каждое число — множитель расхода при определённом RPM.
Например при RPM 2000 и датчике нагрузке 40% расход в час будет: 0.10*40 = 4 л\час

### Встроенный датчик часового расхода

Подсчёт расхода по внутреннему датчику часового расхода автомобиля, который высчитывает сам ЭБУ (присутствует, например,на автомобилях с ЭБУ Январь, Микас). Этот датчик присутствует на многих современных ЭБУ (2020+).

Для этого метода экран «Калибровка расхода» использует отдельную поправку встроенного расхода ЭБУ. По умолчанию она равна 1 и не меняет данные. После калибровки множитель применяется к расходу выбранного топлива; исходный датчик ЭБУ и метод сохраняются.

Нужно понимать что с этим методом расчет ведет ЭБУ автомобиля, и точность зависит от его реализации.

### Датчик циклового расхода (турбодизель)

Подсчёт расхода по внутреннему датчику циклового наполнения цилиндров топливом (CycleConsumption).

Калибровочные коэффициенты для метода «Датчик циклового расхода (турбодизель)»
– Число цилиндров: Число цилиндров в двигателе. Значение по умолчанию: «4» цилиндра
– Коэф. по цикловому расходу: Плотность ДТ.
Значение по умолчанию: 1.
Если ед.измерения циклового расхода в мм3/цикл, то коеф. равен 1.
Если измеряется в мг/цикл, то показатель плотности принято указывать (задан Ростехназдором) равным 0.84


## Калибровка расхода и настройка коэффициентов

Откройте **Настройки → Калибровка расхода → Скорректировать топливо**. Экран выбирает параметр для действующего сохранённого метода и выбранного топлива. Несохранённый выбор в форме настройки метода сначала нужно сохранить.

### По среднему расходу

Это основной режим. Выберите расход по заправкам за последний полный интервал, последние три, 90 дней или все завершённые интервалы. Для hobDrive доступны накопленные средние за неделю, месяц и всё время; рядом показаны дата последних данных и записанный пробег. По умолчанию выбирается доступное месячное среднее, затем недельное или общее. Это существующие накопители, а не скользящие окна за последние 7 или 30 дней.

Обе стороны можно переключить на **Ввести своё значение**. При отсутствии данных программа предлагает другой период или ручной ввод. Периоды могут различаться: совпадение границ не требуется, но результат обозначен как ориентировочный.

Пример: по заправкам 8,4 л/100 км, в hobDrive 8,0 л/100 км. Предложение увеличивает будущий расчёт топлива на 5%. Для MAF AFR 14,7 станет 14,0. Для mpg и км/л программа учитывает обратное направление отношения автоматически.

Проверьте предложение и нажмите **Применить поправку**. Старое среднее не пересчитывается сразу: оно меняется по мере новых поездок. Средние, содержащие данные до известной предыдущей поправки топлива или пробега, видны, но не используются для повторной автокоррекции. Выберите более поздний период или введите новое измерение с текущими настройками и укажите его даты. Повторное применение тех же введённых данных также блокируется.

Для двух видов топлива используются литры выбранного топлива на весь пробег автомобиля, как в журнале заправок. Это может отличаться от показателя расхода только на километры, пройденные на данном топливе. При ручном вводе сравнивайте показатели с одинаковым смыслом.

### По объёму топлива

Для проверки по совпадающим участкам выберите **По объёму топлива**. Здесь нужны **два объёма топлива за одинаковые интервалы**:

- фактически израсходованное топливо по последовательным заправкам до полного бака;
- топливо, рассчитанное hobDrive на этих же интервалах, при показанных текущих настройках.

Начальная полная заправка не входит в расход. Все следующие частичные заправки и конечная полная входят. Две произвольные заправки без достоверных одинаковых уровней бака не определяют израсходованный объём.

На экране можно взять фактический объём из выбранных завершённых интервалов или ввести собственные измерения. Расчётные литры введите из статистики hobDrive за **точно те же интервалы**. Если их исторические границы не совпадают, соберите новый участок. Нельзя подставлять месячный расход в сравнение с другим межзаправочным периодом.

Предпросмотр показывает старое и новое значение, а также ожидаемое изменение последующего расчёта в процентах. После проверки нажмите **Применить поправку**. Поддерживаются десятичная точка и запятая.

### Направление изменения зависит от метода

Обозначим `R = фактический объём / расчётный объём hobDrive` для режима объёмов. В режиме средних `R = расход по заправкам / расход hobDrive`, после перевода обоих значений в л/100 км.

| Метод | Изменяемый параметр | Новое значение |
|---|---|---|
| MAF | Топливо-воздушный коэффициент AFR | `AFR / R` |
| MAP | Объёмная эффективность VE | `VE × R` |
| Форсунки | Производительность форсунки | `производительность × R` |
| Нагрузка двигателя | Глобальный коэффициент по нагрузке | `коэффициент × R` |
| Цикловой расход | Коэффициент по цикловому расходу | `коэффициент / R` |
| Встроенный расход ЭБУ | Поправка встроенного расхода | `поправка × R` |

**AFR и коэффициент циклового расхода стоят в знаменателе.** Увеличение этих параметров уменьшает расчётный расход. Для MAP меняется VE, а AFR, объём двигателя и число цилиндров сохраняются. Для второго топлива изменяются только его параметры.

Пример: по полным бакам израсходовано 60 л, hobDrive посчитал 55 л. `R = 60 / 55 = 1,090909`, то есть требуется увеличить расчёт топлива примерно на 9,09%. Для MAF при AFR 14,7 новое значение равно `14,7 × 55 / 60 = 13,475`. Умножать AFR на `60 / 55` в этом случае было бы ошибкой: расход уменьшился бы ещё сильнее.

Параметры AFR и VE здесь используются как параметры расчётной модели hobDrive. Их изменение не настраивает состав смеси или управление двигателем в ЭБУ. Не изменяйте ради подгонки фактический объём двигателя и число цилиндров.

### Сначала отделите топливо от расстояния

Литры на 100 км зависят от двух величин. Например, при одинаковых 60 л расстояния 600 и 630 км дают 10 и 9,52 л/100 км. Это не доказывает ошибку расчёта топлива. Поправка по среднему может компенсировать и расхождение пробега, приближая показания к выбранному ориентиру. После изменения коррекции пробега проверьте топливную настройку заново. Для отдельной проверки именно топлива используйте объёмы за одинаковый участок.

Подробно о выборе автомобильного одометра или независимого расстояния: [скорость и пробег](speed-diff.md). Пробег GPS в этой версии вводится из проверенного внешнего измерения, автоматического накопителя GPS-пробега для калибровки пока нет.

### Когда результат нельзя считать рекомендацией

Коэффициент не исправляет пропущенные поездки, пропущенные заправки, ручные добавления топлива и пробега, неверные единицы или смену метода в середине периода. Для двух видов топлива сопоставляйте объёмы каждого топлива отдельно.

В режиме объёмов перед применением подтвердите, что hobDrive полностью записал сравниваемые интервалы и на всём их протяжении действовали показанные текущие настройки. Если это неизвестно, начните новый контрольный интервал. Совпадение по одному баку не доказывает точность во всех режимах; проверьте поправку на следующих полных интервалах.

Новая поправка действует на последующие измерения. Уже накопленные значения и старые средние расходы не пересчитываются, а интервалы, пересекающие смену коэффициента, нельзя использовать для повторного расчёта как однородные. Дата, исходные числа и настройки перед применением сохраняются в профиле; на экране показаны последние пять поправок. Это история действий калибровки, а не полная история изменений всех настроек автомобиля.

Часовой расход на прогретом двигателе может помочь заметить грубую ошибку метода, но правило «половина объёма двигателя» не является измерением расхода и не подходит как эталон для точной калибровки.
