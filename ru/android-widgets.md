# Виджеты HobDrive для Android

Android-виджет HobDrive показывает выбранный сенсор прямо на домашнем экране. Он использует тот же способ отрисовки, что и приложение, поддерживает изменение размера и настраивается отдельно для каждого экземпляра.

Функция доступна только на Android. Названия системных команд могут немного отличаться в зависимости от оболочки телефона или магнитолы.

## Как добавить виджет

1. Нажмите и удерживайте свободное место на домашнем экране Android.
2. Откройте системный раздел **«Виджеты»**.
3. Найдите **«Виджет датчиков hobDrive»** и перетащите его на домашний экран.
4. Android откроет экран **«Настройка виджета»**.

Если виджет не появился в списке сразу после обновления HobDrive, перезапустите домашний экран или устройство и проверьте список еще раз.

## Экран «Настройка виджета»

### Выберите датчик

Нажмите кнопку **«Датчик не выбран»** под заголовком **«Выберите датчик»**. В открывшемся списке:

- введите часть пользовательского названия датчика в поле поиска;
- включите поиск по полному ID, если знаете внутренний идентификатор датчика;
- выберите нужную строку.

После выбора кнопка показывает название датчика, а в области **Preview / Предпросмотр** появляется его внешний вид. Кнопка **«Сохранить виджет»** недоступна, пока датчик не выбран.

### Частота обновления

В поле **«Частота обновления»** доступны варианты:

- **5 секунд**;
- **15 секунд**;
- **30 секунд** — значение по умолчанию;
- **60 секунд**;
- **По требованию (коснитесь для обновления)**.

Короткий интервал дает более свежие показания, но требует больше ресурсов. Для показателей, которые не нужно видеть каждую секунду, выбирайте 30–60 секунд или обновление по требованию.

### Предпросмотр и размер

Предпросмотр показывает оформление виджета до сохранения. После добавления измените его размер обычным способом Android: удерживайте виджет и потяните за появившиеся границы. HobDrive перерисует содержимое под новую ширину и высоту.

## Дополнительный XML

Раздел **«Свой XML (опционально)»** предназначен для опытных пользователей. Он позволяет заменить стандартное отображение датчика собственной раскладкой HobDrive. Например:

```xml
<item id="Speed" size="large"/>
```

При изменении XML HobDrive проверяет его и обновляет предпросмотр. Если поле пустое, используется стандартное оформление выбранного датчика. Если редактор показывает ошибку, исправьте XML до сохранения.

Описание элементов и атрибутов: [Спецификация формата Layout](LAYOUT_SPEC_RU.md).

## Сохранение и использование

Нажмите **«Сохранить виджет»**, чтобы завершить настройку, или **«Отмена»**, чтобы не добавлять его.

Поведение касания зависит от выбранной частоты:

- в режиме **«По требованию»** касание обновляет показание;
- при периодическом обновлении касание открывает основное приложение HobDrive.

Можно добавить несколько виджетов и выбрать для каждого собственный датчик, частоту, размер и XML.

## Как изменить уже добавленный виджет

HobDrive поддерживает повторную настройку виджета. Обычно нужно удерживать виджет и выбрать системную команду **«Настроить»**, значок карандаша или пункт параметров виджета. Если оболочка Android не показывает такую команду, удалите виджет с домашнего экрана и добавьте его заново.

Удаление виджета с домашнего экрана удаляет только его конфигурацию и не затрагивает данные HobDrive.

## Если вместо значения нет данных

- Сначала запустите HobDrive хотя бы один раз после установки или обновления.
- Проверьте выбранный профиль автомобиля и подключение OBD-адаптера.
- Сенсор должен быть доступен в текущей конфигурации автомобиля. Некоторые значения появляются только при работающем двигателе или активном соединении.
- Виджет не должен будить спящий телефон только ради обновления. После пробуждения устройства или получения новых данных HobDrive обновит показание.
- Если выбран режим по требованию, коснитесь виджета.
- Если проблема сохраняется, откройте **«Настройка виджета»**, повторно выберите сенсор и проверьте предпросмотр.
