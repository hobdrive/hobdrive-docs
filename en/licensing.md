# Purchase and Licensing

## License terms

One HobDrive license is associated with one vehicle. If you replace the device used in that vehicle, such as a phone, tablet or head unit, you keep the license.

Android and iOS licenses are separate. A license purchased for Android does not work on iOS, and vice versa.

You may use one license on two of your own devices for the same vehicle, for example an Android phone and an Android tablet.

Regular simultaneous use with two or more vehicles requires a separate license for each vehicle.

As an exception, one device may be used with different vehicles in turn for occasional diagnostics. Keep in mind that:

1. HobDrive does not maintain separate statistics for several vehicles in one installation; accumulated data will be mixed.
2. Cloud statistics will also be shared and mixed. Separate ongoing use requires separate licenses.

## License types

### 1. Google Play

A Google Play purchase is associated with the Google account used to buy HobDrive. The device needs that account and periodic internet access.

### 2. App Store (iOS)

An App Store purchase is associated with the Apple ID used to buy HobDrive. The device needs that account and periodic internet access.

### 3. Purchase through the HobDrive website

A website license is associated with the purchase email address and customer name. This license type provides a license key.

#### Offline activation of a website license

Offline activation is available for Android licenses.

Open the website account page, enter the serial number shown on the activation screen, and download the activation key file. Place the file in the application's folder on the device. HobDrive can then run without an internet connection.

### 4. RuStore

A RuStore Android license is associated with the RuStore or VK account used for the purchase. The device needs that account and periodic internet access.

## Recovering a website license

If you have lost the license number, open the [website account page](http://hobdrive.com/payment/orders/manage) and recover access using the email address supplied at purchase.

On iOS, enter a website license number in the separate **Personal Account («Личный кабинет»)** dialog in HobDrive. This is a different activation route from an App Store purchase, which is associated with the purchasing Apple ID.

## Older devices running Android 7

The current HobDrive version does not launch on Android 7. Such a device needs an older compatible release. Links to older application versions are available on the [website account page](http://hobdrive.com/payment/orders/manage).

A manual license number does not make a current build compatible with an older operating system. Use a build that matches both the Android version and the activation method. A RuStore purchase does not automatically become a website license; support considers a separate manual license for each individual case.
